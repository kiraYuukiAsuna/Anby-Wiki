  历史整页为 47/47、4/4。仍需改善遗漏/文字差异，并扩展真实复杂长文、图表和极小区域。

- 真实供应商超时、限流、配额耗尽和告警接收；本轮受控 HTTP 故障不能替代真实场景，
  真实 5 秒期限探针成功，未触发超时。
- 当前固定拓扑的运维上限已定义：最多 2 API/2 Worker、2 上传/2 导入/8 导入模型调用，
  其他模型入口另计；不受控扩容或共享供应商账户前仍需全局租约、预算和背压。
