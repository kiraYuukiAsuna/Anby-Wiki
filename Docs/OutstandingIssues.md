### 8.1 待验收内容

- 独立人工复核阅读顺序、遗漏和额外事实，扩展真实复杂长文/极小区域。
  论文局部片段拼接检查仍为 12/15、小字代理为 13/15，模型报告多处裁剪不完整；
  全文保留和 9 组关键内容检查不能替代完整视觉质量门槛。
- 供应商结算账单、缓存/峰谷/币种核对及失败/取消的未知用量补账，
  负责人批准的账号预算；账号连接探针等直接调用 Provider 的入口仍不在 Gateway
  持久账本内。固定四页每轮 20～24 次/20,479～22,959 输入 Token，
  已低于前轮两阶段成本，但仍高于历史整页 4 次/7,369，不能宣称两阶段更便宜。
- 真实供应商超时、限流、配额耗尽和告警接收；最终代码的十种受控 HTTP 故障通过，
  仍不能替代真实供应商场景及告警投递。
- 当前固定拓扑的运维上限已定义：最多 2 API/2 Worker、2 上传/2 导入/8 导入模型调用，
  其他模型入口另计；不受控扩容或共享供应商账户前仍需全局租约、预算和背压。
- 上传/配额修复已发布，非法 multipart 清理探针通过；本轮 Parser/Prompt/Kernel
  修改尚未部署，需先升级 Kernel 再升级 API/Worker，并验收正式成功上传与恢复；
  旧版本根目录残留清理继续按维护窗口处理。

### 8.2 关闭条件

1. 保持本轮固定语料的全部断言门槛，完成人工阅读顺序、区域遗漏与额外事实复核；
   用扩展真实复杂长文、图表与极小区域补齐完整视觉质量和几何证据。
2. 已报告 Token 及未知用量与最终账单核对，覆盖所有调用入口，落实供应商账号预算；
   固定回归成本门槛持续通过，验证真实超时、429、配额耗尽及告警接收。
3. 完成正式成功上传与恢复冒烟；不受控水平扩展前完成全局租约与背压，
   受控副本总数、导入调用和其他模型入口不得越过供应商总配额。
4. 持续执行固定语料的升级三轮和每周回归；扩展真实语言样本，维持全部断言通过，
   不以历史成功或模型自报 confidence 替代当前解析器质量。
