# ADR-0023：LLM 布局与区域识别分离

- 状态：Accepted
- 日期：2026-10-27
- 依据：[MinerU 借鉴评估与实施方案](../MinerUReferencePlan.md)
- 替代：ADR-0022 中整页一次视觉识别与独立图片 Tesseract 的实现选择

## 决策

PDF、PNG、JPEG 共用账号配置的多模态 LLM：先按缩小页图识别有序布局，再对原始
图像的区域裁图识别内容。模型不生成页码、阅读序号、数据库 ID 或字符位置。
确定性文本解析、图像裁剪和 Schema 校验继续留在 Go Worker；不采用 embedding、
向量数据库、独立 OCR/布局/表格小模型，也不引入 MinerU 依赖或复制上游代码。

PDF 的原生文字仅按精确或纯空白等价匹配回填区域，歧义位置不猜测；遗漏的原生文字
保留为补充分片。扫描页和图片明确标记为视觉识别。页内区域始终映射到原始图像坐标。
布局与识别各有版本化 Prompt/Schema，实际版本都参与解析指纹与审计。

继续保持领域服务权威写入、不可变 SourceVersion/Chunk、Parse 整体失败、
Extraction/ImportPlan 保真门禁与最终 Proposal 人工审核，不改数据库、AST 或发布事务。

## 后果

细小区域可用更高的有效分辨率识别，页布局输出与长文本输出互不挤占。
区域越多，调用数越大；最多三页并行，页内区域串行，使用现有调用与任务总超时。
新解析器不改写历史制品。部署只需更新应用与 Worker 镜像，运行时不再需要 Tesseract。
真实模型的准确率和成本改善必须以实际语料验证，本地编排测试不能代替该结论。
